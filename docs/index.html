Plataforma de afiliados, empresas y subsidios Prueba técnica

Bits Americas · contexto Colsubsidio · línea base documental v1.0 · 20 de octubre de 2026

Aviso de alcance. Este repositorio es un prototipo técnico independiente.

  • No reproduce la arquitectura interna de Colsubsidio ni se conecta a sus sistemas, datos o APIs.
  • Todos los datos son sintéticos: no hay información personal real de afiliados.
  • Las reglas de negocio están marcadas como reglas de demostración, no como políticas oficiales.
  • Ninguna decisión del prototipo equivale a una aprobación real de subsidio.

4. Cómo leer esta documentación

Los documentos 01–06 son la línea base aprobada para construir. El documento 07 describe el código que ya existe y no se considera entregado hasta contrastarlo con los requisitos.

  • Empiece por el documento 01 para entender el alcance y los límites del prototipo.
  • Use el documento 02 como contrato funcional y el 05 para ubicar dónde se prueba cada requisito.
  • Consulte el 04 antes de modificar módulos, contratos o el modelo de datos.
  • El documento 06 indica qué se considera terminado en cada fase.
